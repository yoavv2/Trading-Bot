<objective>
Close the single VERIFICATION blocker (SC4 / REC-01: "every ownership change is gated while an uncertain submission outcome is unresolved", W-3 + W-4) and REVIEW SAF-01 (high) together, because they push the recovery predicate in opposite directions and only one shared definition can satisfy both.

Today there are two definitions of "unresolved": the run-time G2 (`authorize_send` / `_prepare_start` local_unestablished, built on `attempts.proven_not_sent` + `operations._attempt_log_registered`) and the recovery predicate (`recovery._INTENTS_SQL` + `classify_intent`, which never consults the attempt-log proof and whose unflagged branch only sees `unknown` and pending-with-NULL-attempt orders). A5, the submit gate and the issue projection read the predicate, so (a) a legacy zero-attempt pending order and (b) an ambiguous-but-unparked order on an unflagged Job pass A5 while G2 refuses every send; and (SAF-01) an operation-bound zero-attempt order on a flagged Job is blocked forever although the attempt log proves it was never sent.

Purpose: one function, every consumer, one answer. Output: `attempts.classify_submission_evidence` and its adoption by every consumer named below, the predicate surfacing exactly the UNESTABLISHED orders, R3 listing them, and an agreement test that fails if any consumer drifts.
</objective>
