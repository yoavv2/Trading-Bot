# Phase 20.1 Plan 28: WR-01 read model on the shared verdict, WR-08 retry guard Summary

**The operation read model and End result now list exactly the UNESTABLISHED intents (the verdict the strategy gate uses), and the `retry_existing` guard classifies the full attempt history with that verdict, applying a conclusively recorded 4xx as a rejection instead of manufacturing an UNKNOWN order and an uncertain Job.**

## Operator-facing explanation (verbatim)

In GET /api/v1/execution-operations/{id} and the End result, `unresolved_intents[].state` is always `ambiguous` (the outcome is not established, the strategy is blocked), while `intents[].state` keeps the lifecycle display (`registered_unsent`, `submitted`, ...), so the same intent can show `submitted` in `intents` and `ambiguous` in `unresolved_intents` when its order was accepted without a broker id; the unresolved list is the one that decides blocking.

## Reachability finding (read before relying on the guard)

A pinned intent that is ALREADY bound to its order and whose history is REJECTED, ambiguous or unfinished is never loaded as sendable (`_load_open_intents` filters on `derive_intent_state`), so the loop never registers it again. The guard is reached for a PLANNED intent whose identity (strategy / session / symbol / side / quantity) resolves to an OLDER retryable order that was proven not sent when the operation started and gained its history afterwards. The new tests drive exactly that shape through the product loop (operation 1 registers NVDA unsent and is ended; operation 2 is [AAPL, NVDA]; the arranged attempt rows land on the older NVDA order while AAPL's POST is in flight, or between NVDA's permission check and its registration via a wrapper on `_candidate_for_view`). In the first window the per-intent permission check (strategy gate) stops ambiguous / unfinished histories before the guard (paused `outcome_unresolved`, order stays `submission_failed`); in the second window only the guard stands, and it parks UNKNOWN and raises. Both are asserted.
