<objective>
Deliver PROV-01 (D-25, D-26; G-3, R-25): an evaluation records an input manifest of everything it read, so execution can confirm the evaluation used the CURRENTLY VALID data and signal settings. Every read through the shared accessors is recorded as a request with its resolved as-of bound and a SHA-256 digest of its result (empty results included), plus a digest of the signal settings, in the risk run's existing `result_summary`. Verification re-executes the recorded requests as recorded; only changed values, added/removed rows or changed signal settings make the evaluation stale. `updated_at` is never used, a no-op re-ingest is not stale, and a new position, a risk-limit change or a calendar synced ahead never invalidates it.

Purpose: a corrected or backfilled bar after evaluation currently goes unnoticed (and on 29 Sep a symbol that was entirely absent could later be ingested while the stale decisions stayed "valid"). Provenance is deliberately separate from current portfolio risk (D-26): cash, positions, open orders and risk limits are re-checked fresh by 20.1-11.

Wave-4 file ownership: this plan shares no file with the already-written 20.1-08. This plan creates NO migration (the manifest lives in the existing JSON `result_summary`).
