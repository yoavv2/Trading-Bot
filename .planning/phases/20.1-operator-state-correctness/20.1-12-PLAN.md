- Checks use persisted evidence only. A2/A4 and the exposure half of A3 read the LATEST account-scope reconciliation run (scope 'account', not a strategy-level run); A3's position count reads the latest broker-observed snapshot; if no account reconciliation or no broker-observed snapshot exists the check fails with reason_code `no_account_reconciliation` / `no_broker_observed_snapshot` (fail-closed). - A1 and the GET use the pure effective operation state; the control does not apply lazy expiry (an expired but untouched operation counts as ended; its dispositions are applied at its next touch).

- Reaffirm (target equals current) evaluates no checks: it is idempotent by target state and harmless.
