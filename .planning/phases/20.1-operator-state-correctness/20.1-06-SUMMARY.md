# Phase 20.1 Plan 06: Evaluation Input Manifest (PROV-01) Summary

**Every risk evaluation records the reads it made through the five shared accessors (resolved as-of bounds, SHA-256 result digests, empty results included) plus a signal-settings digest in `result_summary['evaluation_manifest']`; verification re-executes them as recorded in at most 4 batched, read-only statements and paper-session submit refuses a stale evaluation with a typed 409 (`evaluation_data_changed` / `strategy_settings_changed`), while no-op re-ingests, new positions, risk-limit changes and calendar syncs never invalidate it.**
