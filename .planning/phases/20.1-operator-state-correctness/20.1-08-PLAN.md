<objective>
Deliver ACCT-01: owner-less, account-level broker sync and reconciliation (D-09) with dedicated owner-less storage (R-31, J-3). Both existing Job types gain a `scope: account | strategy` payload field. Account scope is report-only: it assigns nothing to any strategy, submits nothing, creates no position, and lifts no gate by itself. Its stored result is what the recovery predicate (20.1-10), the handover checks (20.1-12) and analytics read.

Purpose: seeding (D-04 A6), handover-to-none, and recovery of a former owner's uncertainty all need a broker check that works with NO owner. `strategy_runs.strategy_id` is NOT NULL (`db/models/strategy_run.py:55-58`), so the result cannot be a strategy run without borrowing an arbitrary strategy, which J-3 forbids.
Output: migration 0024 + model; `sync_account_state`, `reconcile_account`, `latest_standalone_reconciliation`; scope-aware specs/handlers; additive catalog/read fields; migration, service, spec and handler tests.
</objective>
