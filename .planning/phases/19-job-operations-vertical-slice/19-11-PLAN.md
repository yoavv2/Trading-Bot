|----------|-------------|
| operator form input -> POST /api/v1/jobs | Untrusted payload crosses to the API |
| URL query params -> form pre-fill | ?type and ?strategy_id are attacker-controllable via links |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-11-01 | Tampering | payload | mitigate | Server-side strict validation is authoritative (Plan 06, extra="forbid"); form only sends the three keys |
| T-19-11-02 | Tampering | duplicate submissions | mitigate | Idempotency-Key per form instance, reused on identical retry, rotated on payload change (tested) |
| T-19-11-03 | Spoofing / XSS | ?type / ?strategy_id rendering | mitigate | Rendered as React text and used only via encodeURIComponent in hrefs; unknown type shows static copy; strategy_id only pre-selects an option |
| T-19-11-04 | Elevation of Privilege | submit on disabled deploy | mitigate | Controls disabled unless capability "enabled"; backend 403 guard is authoritative |
</threat_model>
