|----------|-------------|
| API JSON -> React render | result_summary (handler-authored), failure_message, resource ids/kinds are untrusted |
| operator click -> cancel mutation | Destructive action on a public-capable UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-12-01 | Information Disclosure / XSS | JobResultSummaryPanel, JobHeaderPanel failure_message | mitigate | React text only, JSON.stringify for nested values; boundary test forbids dangerouslySetInnerHTML in all non-test console files |
| T-19-12-02 | Spoofing | resource links | mitigate | Hrefs built only from the closed map (2) via resourceHref; server-provided links.self is never used as an href; unknown kinds render without a link |
| T-19-12-03 | Elevation of Privilege | cancel trigger on disabled deploy | mitigate | Trigger disabled unless capability "enabled"; backend 403 authoritative |
| T-19-12-04 | Denial of Service | polling | mitigate | 3s polling only while non-terminal, stops at terminal (tested), pauses when hidden |
</threat_model>
