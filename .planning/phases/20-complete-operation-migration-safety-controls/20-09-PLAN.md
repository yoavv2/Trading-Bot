## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP payload -> PaperSessionSubmissionSpec | Untrusted JSON, including an optional run id reference |
| handler -> broker order submission | Real (paper) broker side effects inside one opaque call |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-09-01 | Tampering | risk_run_id | mitigate | UUID parse + is_eligible_risk_run (SUCCEEDED, same strategy, same session) before persistence; typed 422 |
| T-20-09-02 | Repudiation | cancel after submission | mitigate | QUEUED_ONLY + no in-handler checkpoint: a session that submitted orders is never labelled CANCELLED (D-02/D-03) |
| T-20-09-03 | Tampering | duplicate broker submission via retry | mitigate | external_broker_session_started marker makes any post-start handler_error outcome_uncertain, which triggers the D-19 reconcile-first block (enforced in Plan 10); client_order_id idempotency (Phase 7) remains the broker-level backstop |
| T-20-09-04 | Denial of Service | concurrent sessions | mitigate | Existing advisory lock (Phase 8) unchanged; conflict surfaces as domain_conflict, not handler_error |
| T-20-09-05 | Elevation of Privilege | strategy/kill-switch gating | mitigate | Gating logic in run_paper_session untouched; blocked outcomes surface as SUCCEEDED with action visible (D-05) |
</threat_model>
