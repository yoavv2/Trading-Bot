## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| registry/mapping -> catalog API | The console decides which actions to offer from these fields |
| DB -> job list API | Unauthenticated GET exposes failure messages, which may contain internal detail |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-07-01 | Spoofing | Catalog says a type has no broker effect or no prerequisite when the handler has one | mitigate | Single mapping; pinned per-type table and prerequisites; spec-vs-mapping consistency test; completeness test fails a type without a mapping |
| T-21-07-02 | Elevation of Privilege | An API-only or exposure-increasing type offered as a normal console action | mitigate | console_submission api_only for paper-session and record-external-activity pinned; submits_orders pinned; the catalog route performs no mutation |
| T-21-07-03 | Information Disclosure | Long failure messages leaking stack or payload detail through the list | mitigate | Truncation to job_failure_message_max_chars with a truncated flag; the full message stays on the detail read as today |
| T-21-07-04 | Denial of Service | N+1 detail loads per listed Job | mitigate | Batched IN-queries, <= 4 statements asserted at 1 and 50 Jobs and at limit 1 and 100, with a negative probe |
| T-21-07-05 | Tampering | List read writing state | mitigate | read_only_session_scope plus write-spy |
| T-21-07-06 | Repudiation | List outcome diverging from the detail outcome | mitigate | Same helper functions feed both; parity test over every status and type |
</threat_model>
